# esp32-Plastic_Glass_Bottle-ai

מיון בקבוקים על מסוע: זיהוי **פלסטיק** ו**זכוכית** עם מודל YOLO, והפעלת ESP32.

```
📱 טלפון / 💻 מחשב (/camera)  →  ☁️ שרת Render (AI)  ←  ESP32 שואל כל 0.3 שניות (/result)
```

## איך זה עובד
1. דף המצלמה (`/camera`) שולח תמונה לשרת בערך פעם בשנייה.
2. השרת מזהה בקבוק בתוך המלבן **SORTING ZONE**.
3. כשאותו חומר מזוהה ב-2 תמונות ברצף, נספר **בקבוק אחד** (אירוע עם מספר).
4. הבקבוק הבא נספר רק אחרי שהבקבוק הזה **יצא מהמלבן**, כלומר המלבן ריק במשך 1.5 שניות. ככה בקבוק שנוסע על המסוע נספר פעם אחת בלבד.
5. ה-ESP32 רואה מספר אירוע חדש ומגיב:
   - **זכוכית**: לד GPIO 2 מהבהב 3 פעמים מהר
   - **פלסטיק**: לד GPIO 2 מהבהב 2 פעמים מהר
   - בנוסף מודפס בטרמינל: סוג החומר, אחוז הביטחון ומספר הבקבוק.

## קבצים
| קובץ | מה הוא |
|---|---|
| `app.py` | שרת Flask: דף מצלמה, זיהוי (LiteRT, בלי PyTorch) וספירת בקבוקים |
| `waste_final_v1.tflite` | המודל (plastic, paper, metal, glass; משתמשים רק בפלסטיק ובזכוכית) |
| `esp32_client.py` | קוד MicroPython ל-ESP32 |
| `requirements.txt` | ספריות לשרת |

## הגדרות בשרת (Render → Environment)
- `DEVICE_TOKEN`: הסיסמה של דף המצלמה ושל ה-ESP32 (חובה)
- `CONF_THRESHOLD`: סף הביטחון (ברירת מחדל 0.65)

## ESP32
ב-`esp32_client.py` משנים את `SSID`, `PASSWORD` ו-`DEVICE_TOKEN`, ומעלים ל-ESP32 עם Thonny.
את הסיסמאות האמיתיות לא מעלים ל-GitHub (הריפו ציבורי).
